## ৩০ সেকেন্ডে মূল কথা

**Claude Code হলো এমন একটা AI, যেটা আপনার কম্পিউটারেই থাকে।** এটা আপনার file পড়ে, code লেখে, command চালায়, আর জিনিস বানিয়ে দেয়। আপনি এর সঙ্গে সাধারণ ইংরেজিতে কথা বলেন।

ChatGPT যদি এমন কেউ হয় যাকে আপনি পরামর্শের জন্য message করেন, তাহলে Claude Code হলো পাশে বসা একজন colleague, যার হাতে আপনার আসল project আছে। শুধু suggestion না। সত্যিকারের output। সত্যিকারের file।

## ChatGPT-এর সঙ্গে এর পার্থক্য কী?

সবাই এই প্রশ্নটাই করে। সোজাসাপ্টা উত্তর:

| | ChatGPT | Claude Code |
|---|---|---|
| **কোথায় চলে** | browser tab-এ বা ChatGPT app-এ | আপনার কম্পিউটারে (অথবা browser-এ) |
| **কী দেখতে পায়** | শুধু আপনি যা paste করেন | আপনার পুরো project folder |
| **কী করতে পারে** | text-এ উত্তর দেয় | file পড়ে, file লেখে, command চালায়, code test করে, deploy করে |
| **Memory** | Memory চালু থাকলে আপনার preference আর আগের chat-এর details মনে রাখে | আপনার preference, project আর আগের সিদ্ধান্তগুলো মনে রাখে |
| **Output** | text, যা আপনি copy-paste করেন | আপনার কম্পিউটারে আসল file |
| **সবচেয়ে ভালো যেখানে** | প্রশ্ন আর brainstorming | আসল জিনিস বানানো, ঠিক করা আর ship করা |

কোনোটাই "বেশি ভালো" না। দুটো আলাদা কাজের জন্য আলাদা tool।

Browse করার সময় চট করে একটা উত্তর দরকার? ChatGPT। কিছু বানাতে হবে, একটা bug ঠিক করতে হবে, বা কোনো workflow automate করতে হবে? Claude Code।

## আসলে এটা কী কী করতে পারে?

মানুষ প্রতিদিন যেসব আসল কাজে এটা ব্যবহার করে, তার কয়েকটা নিচে দেখুন।

### আপনি যদি একদম নতুন হন
- **একটা personal website বানান** একদম শূন্য থেকে, মোটামুটি ৩০ মিনিটে
- **বিরক্তিকর কাজ automate করুন**, যেমন file rename করা, folder গোছানো বা spreadsheet process করা
- **Code করা শিখুন**, Claude পাশে থেকে বুঝিয়ে দেবে আর আপনার সঙ্গে বানাবে

### আপনি যদি প্রোডাক্ট ম্যানেজার হন
- **Meeting notes থেকে Jira ticket বানান** কয়েক সেকেন্ডে
- **Competitive analysis লিখুন**, বিভিন্ন product নিয়ে research আর তুলনা করে
- **Slide deck outline আর status report বানান** আপনার project data থেকে

### আপনি যদি ডেভেলপার হন
- **আরও দ্রুত feature ship করুন**, এমন একটা AI দিয়ে যে আপনার codebase চেনে
- **আন্দাজে না গিয়ে ধাপে ধাপে debug করুন**
- **পুরো codebase নিরাপদে refactor করুন**, আগে test লিখে নিয়ে

### আপনি যে-ই হোন
- আপনার নিজের লেখার style-এ document draft করুন
- web ঘেঁটে যেকোনো topic নিয়ে research করুন
- আপনার জন্য বানানো material দিয়ে job interview-এর প্রস্তুতি নিন

## Code জানতে হবে কি?

না। জানি, কথাটা marketing line-এর মতো শোনায়। কিন্তু তা না।

Claude Code শুরু হয়েছিল developer-দের tool হিসেবে, কিন্তু এখন এটা তার চেয়ে অনেক বড় কিছু হয়ে উঠেছে। Desktop বা web app ব্যবহার করলে আপনাকে কখনো terminal খুলতে হবে না। আপনি যা চান তা লিখবেন, Claude বের করবে কীভাবে করতে হয়, আর আপনি দেখে নেবেন সে কী বানাল।

এই site-এর tutorial-গুলো এমন মানুষের জন্য লেখা, যারা কখনো code ছুঁয়েও দেখেননি। আপনি কী চান সেটা বুঝিয়ে বলতে পারলেই Claude Code দিয়ে বানাতে পারবেন।

## এর পেছনের model-গুলো

Claude Code চলে তিনটা AI model-এ। আপনাকে হাতে বেছে নিতে হবে না: প্রতিটা paid plan-এ এটা Opus 5.5 দিয়ে `medium` effort-এ শুরু হয়, আর `/model` দিয়ে বদলাতে পারেন। তবে কী নিয়ে কাজ করছেন তা জানা থাকলে সুবিধা হয়:

- **Claude Opus 5.5**: সবচেয়ে গভীরভাবে চিন্তা করে, আর এটাই default। 1M <VocabBridge term="token" explanation="text-এর ছোট একটা টুকরো (মোটামুটি একটা শব্দ), যা দিয়ে AI model মাপে সে কতটা পড়ল আর লিখল।">token</VocabBridge> <VocabBridge term="context window" explanation="AI একবারে কতটা text 'দেখতে' পায়: অনেকটা যেন একসঙ্গে মাথায় কত পাতা ধরে রাখতে পারে।">context window</VocabBridge>। সমস্যা সত্যিই কঠিন হলে আর প্রথমবারেই ঠিক উত্তর লাগলে এটা ব্যবহার করুন।
- **Claude Sonnet 5.5**: দ্রুত আর দক্ষ। Opus-এর অর্ধেক দামে প্রতিদিনের বেশিরভাগ কাজ সামলায়।
- **Claude Haiku 5.5**: সবচেয়ে দ্রুত আর সবচেয়ে সস্তা; 100K token পর্যন্ত prompt-এ Sonnet-এর দামের বিশ ভাগের এক ভাগ ($2 / $0.10 = 20)। ছোটখাটো edit, summary আর সহজ lookup-এর জন্য দারুণ।
